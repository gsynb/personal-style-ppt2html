# Institution Brand Rules

Use this file when the user asks to incorporate school, lab, group, department, or company identity.

## Required Inputs

Ask for or locate user-provided:

- official logo files,
- official color values,
- lab or institution names in the required language,
- required footer wording,
- any title-slide or acknowledgment constraints.

## Safe Defaults

- Use a small top-left lockup or subtle footer mark.
- Keep the institution element secondary to the academic claim.
- Use official assets directly; do not recreate logos with image generation.
- If no logo is available, use text-only lockup until the user provides one.

## Do Not

- Guess a university logo, seal, emblem, or official color.
- Use generated images for identity marks.
- Stretch, crop, recolor, or outline official marks unless the provided brand guide allows it.
- Let institution decoration compete with figures, equations, or results.
